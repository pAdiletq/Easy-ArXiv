Expression syntax

Use parentheses and explicit multiplication: 2*x. Write powers as x^2 and functions as sin(x), sqrt(x) or exp(x).

Example: exp(-x^2). Write m*c for multiplication; mc is a single variable name. A matrix can be written as [[1,0],[0,1]].
